# 第九篇：前沿与实践 — 业界案例 + 动手入门

## 本篇章回答的问题

| Q | 问题 | 核心要点 |
|---|------|---------|
| Q1 | [Meta / Google / Microsoft 的超大集群长什么样？](./01-超大集群长什么样.md) | 四巨头的芯片、互联、供电与冷却对比；瓶颈在网络、供电和故障率，不在 GPU |
| Q2 | [液冷会成为标配吗？](./02-液冷会成为标配吗.md) | DLC vs 浸没式两大路线；机柜上到 120-140 kW 后风冷出局 |
| Q3 | [全光互联、CXL 内存池化意味着什么？](./03-全光互联CXL内存池化意味着什么.md) | 内存墙；CXL 池化的是主机 DRAM，全光互联拉长访问距离 |
| Q4 | [自己动手搭建一个小集群怎么入门？](./04-自己动手搭建一个小集群怎么入门.md) | 2-4 节点最小集群的选型、预算、供电现实与 Slurm |
| Q5 | [学习路径推荐](./05-学习路径推荐.md) | 论文、书单、顶会与社区，把"知道"变成"能动手" |

**核心因果链**：超大集群先把网络和供电堆到极限（Q1）→ 功率密度把风冷逼到退场（Q2）→ 内存墙逼出 CXL 和全光互联（Q3）→ 但大部分团队只需要一个小集群，那就自己搭（Q4）→ 剩下的交给一条能持续走下去的学习路径（Q5）
