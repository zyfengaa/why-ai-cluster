# Q: 液冷会成为标配吗？

## 为什么会有这个问题

2019 年，你走进一个数据中心——全是风扇声、空调冷风。GPU 也就是 300W，风冷完全够用。

2026 年，Blackwell GB300 单 GPU 功耗 700W，整机架 163 kW。2027 年的 Rubin NVL144 整机架 300+ kW。

**在 300 kW 的机架面前，风冷就像用风扇吹一个炼钢炉。**

## 解决什么问题

液冷要解决的核心问题：**当功率密度超过风冷的散热极限时，怎么把热量从 GPU 上带走。**

### 风冷的极限

```
风冷的散热能力：~30-40 kW/rack
  超过 40 kW → 风量需求太大 →
    · 风扇噪音 > 90 dB（工业级噪音）
    · 冷通道温度分布不均
    · 需要更大的机房（间距 2m+）
    · 功耗中 30% 以上给风扇和空调

GPU 的发展：
  H100 (700W) → GB300 (700W+) → Rubin (1800W 单芯片)
  8×H100/rack = ~6 kW（仅 GPU）→ GB300 NVL72 = 163 kW/rack
  
  差值：6 kW → 163 kW = **27倍**
  风冷极限：~40 kW
  → 163 kW 的机架，必须液冷
```

### DLC（Direct-to-Chip）的工作原理

```
┌──────────────────────────────────────┐
│  热交换单元（CDU - Coolant          │
│  Distribution Unit）                  │
│  ┌──────────────────────────────┐   │
│  │ 一次侧：外部冷水（25°C）     │   │
│  │ 二次侧：内部冷却液（~45°C）  │   │
│  └──────────────────────────────┘   │
│         ↓ 冷却液管道                 │
│  ┌──────────────────────────────┐   │
│  │ 冷板（Cold Plate）直贴 GPU   │   │
│  │ 冷却液流过 GPU 上方的微通道  │   │
│  │ 带走 60-80% 的热量           │   │
│  └──────────────────────────────┘   │
└──────────────────────────────────────┘
```

### 液冷的两大路线

| 类型 | 原理 | 密度 | 成本 | 复杂度 | 市场占比 |
|------|------|------|------|--------|---------|
| **DLC（冷板式）** | 冷却液流经 GPU 上的冷板 | 60-100 kW/rack | 中 | 低 | **52-60%** |
| **浸没式** | 整个服务器浸入介电冷却液 | 200+ kW/rack | 高 | 高 | 20-25%（亚太）|

**2026 年的共识**：DLC 是"保守但可靠"的选择，浸没式是"极致但复杂"的选择。

## 🛠 实操指南

### 📋 决策指南：你需要液冷吗？

```
你当前的 GPU？
├─ H100 SXM（700W）→
│   ├─ ≤ 8 卡/机架 → 风冷足够
│   └─ > 8 卡/机架 → 建议 DLC
│
├─ GB200/GB300（700W+）→
│   └─ 全部需要 DLC（NVIDIA 强制要求的安装条件）
│
└─ Rubin（1800W）→
    └─ 必须液冷，风冷不存在选项
```

```python
# 判断你是否需要液冷的计算器
gpu_power = 700  # W
gpus_per_rack = 8
total_kw = gpu_power * gpus_per_rack / 1000

# 加上 CPU、内存、交换机的功耗
rack_total = total_kw * 2.5  # 粗略：GPU 占机架 40% 功耗
print(f"机架总功耗: {rack_total:.1f} kW/rack")

if rack_total < 20:
    print("✅ 风冷足够")
elif rack_total < 40:
    print("⚠️ 风冷可接受但建议 DLC 预留")
elif rack_total < 60:
    print("🔶 建议 DLC 液冷")
elif rack_total < 100:
    print("🔴 必须 DLC 液冷")
else:
    print("🚫 必须液冷，考虑两相浸没式")
```

### 🔧 自己动手验：检查你的散热状况

```bash
# 1. 检查 GPU 是否在降频工作
nvidia-smi -q -d PERFORMANCE | grep "Performance State"
# P0 = 最佳性能，P2/P8 = 降频

# 2. 检查 GPU 温度和历史峰值
nvidia-smi -q -d TEMPERATURE | grep -E "GPU Current|Slowdown|Shutdown"
# Slowdown Temp：超过此温度开始降频
# Shutdown Temp：超过此温度自动关机

# 3. 对比不同散热方式的 GPU 温度
# 冷板液冷的 GPU 温度一般在 55-65°C
# 风冷的 H100 一般在 70-85°C
# 如果 > 85°C → 降频风险极高

# 4. 检查 CDU（液冷分配单元）的运行状态
# 一般通过 DCIM（数据中心基础设施管理）API 获取
curl -s http://cdu-monitor:9090/metrics | grep -E "coolant_temp|cdu_power|flow_rate"
# 冷却液入口温度：推荐 20-28°C
# 冷却液出口温度：推荐 40-50°C
# 温差 > 5°C：CDU 散热效率正常
```

### ⚠️ 常见误区

- **误区**："液冷太贵，省电也省不回成本"
  - **实际**：在 H100 以上密度，**液冷节省的电力成本（PUE 从 1.4 降到 1.08）+ 更高的 GPU 密度（同面积放更多 GPU）会在 1-2 年内回本**。对于 Blackwell 级别的 GPU，液冷已经是一个"不选就没办法部署"的选项。

- **误区**："液冷容易漏水，风险太大"
  - **实际**：现代 DLC 系统使用**介电冷却液**（不导电），即使泄漏也不会短路。接头设计为"干断接"（断开时自动截止）。2026 年 DLC 的故障率已经低于风冷的 CRAC 空调故障率。

- **误区**："浸没式一定会取代 DLC"
  - **实际**：DLC 和浸没式是**并存的两个市场**，不是替代关系。DLC 适合现有数据中心改造（加冷板就行），浸没式适合新建的大型 AI 训练工厂。**DLC 占主流至少到 2028+。**

### 📊 底线数字速查

| 冷却方式 | 散热密度 | PUE（典型）| 改造成本 | 适用 GPU |
|---------|---------|-----------|---------|---------|
| 风冷 | < 40 kW/rack | 1.3-1.6 | $0 | H100 PCIe |
| DLC | 60-100 kW/rack | 1.08-1.15 | +20% | H100+ / B200+ |
| 单相浸没 | 100-200 kW/rack | 1.05-1.10 | +40% | 定制服务器 |
| 两相浸没 | 200+ kW/rack | 1.03-1.05 | +60%+ | 新建设施 |

### 💡 一句话记住

> **"液冷在 2026 年已经不是'可选项'——对于 Blackwell 级别以上的 GPU，它是唯一的选项。DLC 是当前的主流（市场 60%、改造成本可接受、PUE 1.08），浸没式是未来的方向（200+ kW/rack 的极致密度）。一句话总结：GPU 到了 700W+，风冷就下课了。"**
