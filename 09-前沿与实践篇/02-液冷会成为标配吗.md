# Q: 液冷会成为标配吗？

## 为什么会有这个问题

2019 年，你走进一个数据中心——全是风扇声、空调冷风。GPU 也就是 300W，风冷完全够用。

2026 年，GB300 单 GPU 的 TDP 是 **1,400W**，一台 NVL72 整柜约 **132 kW**。Rubin 一代还会更高。

**但另一边，8 卡 DGX B300 整机约 14-15 kW，今天依然可以风冷交付。**

所以"液冷会成为标配吗"这个问题，答案不取决于 GPU 本身，而取决于**机柜功率密度**。

## 解决什么问题

液冷要解决的核心问题：**当单个机柜的功率密度超过风冷的散热能力时，怎么把热量从 GPU 上带走。**

### 风冷的边界

```
风冷的散热能力：大致在 30-40 kW/rack 一档
  超过这个量级 → 风量需求急剧上升 →
    · 风扇功耗占整柜功耗的比例明显上升
    · 冷通道温度分布不均，出现局部热点
    · 需要更大的机房（机柜间距、风道）
    · 噪音、维护成本同步上升

机柜功率密度的阶梯：
  8×H100 服务器整机     ≈ 10-14 kW      → 风冷无压力
  8×DGX B300 整机       ≈ 14-15 kW      → 风冷可行（GB300 单卡 1,400W，
                                            但整机柜风冷仍可交付）
  GB300 NVL72 整柜      ≈ 132 kW        → 必须 DLC
  Rubin NVL144（下一代） → 更高          → 必须 DLC

关键点：GB300 单卡 1,400W ≠ "8 卡 GB300 必须液冷"。
决定权在整机柜密度：NVL72 这种 72 卡一体柜才把风冷逼出局。
```

### DLC（Direct-to-Chip）的工作原理

```
┌──────────────────────────────────────┐
│  CDU（Coolant Distribution Unit，    │
│  冷量分配单元）                        │
│  ┌──────────────────────────────┐   │
│  │ 一次侧：楼宇冷冻水（ Facility │   │
│  │  Water System，25-32°C）      │   │
│  │ 二次侧：机柜内冷却液回路       │   │
│  │ 两侧通过板式换热器隔离         │   │
│  └──────────────────────────────┘   │
│         ↓ 二次侧冷却液管道            │
│  ┌──────────────────────────────┐   │
│  │ 冷板（Cold Plate）直贴 GPU    │   │
│  │ 冷却液流过冷板微通道带走热量  │   │
│  │ CPU/内存/硬盘仍靠风冷排热     │   │
│  └──────────────────────────────┘   │
└──────────────────────────────────────┘
```

**冷却液的选择**（这是最容易搞错的地方）：

- **DLC 冷板式**：用**水-乙二醇混合液**（去离子水 + 乙二醇，兼顾防冻、防腐蚀、抑菌）。它**是导电的**——所以 DLC 的安全设计重点不是"液体不导电"，而是防漏。
- **浸没式**：用**介电液**（氟化液/合成油，不导电），整个服务器泡在里面，所以不怕漏。

### DLC 的安全设计：漏液检测与快接头

```
漏液风险控制（DLC 是导电液体，这是 DLC 最大的工程门槛）：
  · 负压运行：二次侧回路维持轻微负压，漏了是吸气不是喷液
  · 泄漏传感绳：沿机柜底部和关键接头布设，碰到液体立即告警
  · 干式快接头（Dry Break）：断开时两侧自动截止，几乎不滴漏
  · 每机柜独立回路：单柜漏液不影响相邻机柜

余热回收：
  DLC 的二次侧出水温度（40-50°C）比风冷空调回风更"值钱"，
  温度越高越容易直接用于区域供暖或生活热水——
  这是液冷数据中心打"碳排牌"的主要论据。
```

### 液冷的两大路线

| 类型 | 原理 | 适用密度 | 相对成本 | 现状 |
|------|------|---------|---------|------|
| **DLC（冷板式）** | 水-乙二醇流经 GPU 冷板 | 从 30-40 kW 到 100+ kW/rack | 中 | AI 数据中心的主流选择 |
| **浸没式（单相/两相）** | 整机浸入介电液 | 更高密度，且天然无漏电风险 | 高 | 有落地案例，但远非主流 |

**2026 年的行业状态**：DLC 是 AI 集群的默认路径；浸没式在高密度和特定改造场景（如加密矿机转 AI）有自己的生态，但两者是并存关系，不是替代关系。

## "液冷一定比风冷省电"吗？

**不一定。这句话只有在特定条件下才成立。**

液冷对电力的真实影响取决于四个变量：

```
1. PUE（Power Usage Effectiveness）
   PUE = 总用电 / IT 用电，越接近 1 越好
   · 风冷数据中心典型 1.4-1.6，优秀 1.2-1.3
   · 液冷数据中心理论上可以做到 1.1 以下
   · 但前提是 CDU 和水泵本身不成为新的耗电大户

2. 气候
   · 液冷允许更高的冷却液温度 → 更长年份可以走"免费冷却"
     （直接用室外冷源，不开压缩机）
   · 在阿姆斯特丹和在上海，同一套系统的省电比例完全不同

3. 电价
   · 工业电价高的地区，省电才有明显的账面价值
   · 电价便宜的地区（如靠近电厂的项目），省电的回本期被拉长

4. CDU 效率与维护
   · CDU 水泵、板换温差、管路阻力都会吃掉收益
   · 二次侧进出水温差设计不当，流量翻倍、泵功耗跟着翻倍
```

所以正确的说法是：**液冷在功率密度上是必选项（NVL72 没有"风冷版"），在经济性上是条件项（取决于气候、电价、CDU 效率和负载率）**。把"液冷省电"当作普适结论，会做出错误的预算决策。

顺带一个相关的指标：**WUE**（Water Usage Effectiveness，每 kWh IT 用电消耗的升水）。蒸发冷却省电但耗水，干冷器省水但耗电——液冷方案选型时 PUE 和 WUE 经常是互相牵制的，尤其在水紧张的地区。

## 🛠 实操指南

### 📋 决策指南：你需要液冷吗？

```
你当前的 GPU？
├─ H100/H200 SXM（700W）→
│   └─ 8 卡整机 10-14 kW → 风冷足够
│
├─ B300 级 8 卡整机（约 14-15 kW）→
│   └─ 仍然可以风冷；新建机房建议做 DLC 预留（管路+机柜位）
│
├─ GB200/GB300 NVL72（约 132 kW/柜）→
│   └─ 必须 DLC，没有风冷选项
│
└─ Rubin 世代 →
    └─ 同上，必须 DLC，且向更高流量密度演进
```

```python
# 判断你是否需要液冷的计算器
gpu_power = 1400          # W，GB300
gpus_per_rack = 72        # NVL72 整柜
total_kw = gpu_power * gpus_per_rack / 1000
print(f"GPU 总功耗: {total_kw:.1f} kW/rack")  # 约 100 kW
# 加上 CPU、内存、NVSwitch、网络，NVL72 整柜约 132 kW

rack_total = 132  # kW

if rack_total < 20:
    print("✅ 风冷足够")
elif rack_total < 40:
    print("⚠️ 风冷可接受，建议 DLC 预留")
elif rack_total < 80:
    print("🔶 建议 DLC 液冷")
else:
    print("🔴 必须 DLC 液冷")
```

### 🔧 自己动手验：检查你的散热状况

```bash
# 1. 检查 GPU 是否在降频工作
nvidia-smi -q -d PERFORMANCE | grep "Performance State"
# P0 = 最佳性能，P2/P8 = 降频

# 2. 检查 GPU 温度与阈值
nvidia-smi -q -d TEMPERATURE | grep -E "GPU Current|Slowdown|Shutdown"
# Slowdown Temp：超过此温度开始降频
# Shutdown Temp：超过此温度自动关机

# 3. 经验参照（不同机型的具体值以官方文档为准）
# 冷板液冷的 GPU 温度一般在 55-65°C
# 风冷同代 GPU 通常更高；持续逼近 Slowdown 阈值就是散热不足

# 4. 有 CDU 的环境，通过 DCIM/监控系统检查：
#    · 二次侧冷却液供回水温度（温差反映带走的热量）
#    · 流量、泵状态、液位
#    · 泄漏传感绳状态
# 这些指标一般不在 nvidia-smi 里，而在机房基础设施侧
```

### ⚠️ 常见误区

- **误区**："液冷一定比风冷省电"
  - **实际**：不一定。液冷允许更高的冷却液温度、减少风机功耗，**有**做到更低 PUE 的潜力；但实际省多少取决于气候、电价、CDU 效率和负载率。有些改造项目液冷装完 PUE 反而没降——问题通常出在 CDU 选型和一次侧水温。液冷在 NVL72 级密度下是**必选项**，在低密度下是**经济性问题**。

- **误区**："DLC 用的是不导电的介电液，漏了也没事"
  - **实际**：DLC 冷板回路用的是**水-乙二醇，是导电的**。用介电液的是浸没式。DLC 的安全靠的是负压运行、泄漏传感、干式快接头和独立回路这些**防漏设计**，而不是液体本身不导电。

- **误区**："浸没式会取代 DLC"
  - **实际**：两者并存。DLC 是 AI 集群的主流路径（改造成本低、供应链成熟），浸没式适合超高密度和特定新建场景。说"某一种将在 X 年全面胜出"都没有可靠依据。

- **误区**："PUE 1.08 一定比 1.3 省钱"
  - **实际**：PUE 只是能耗效率，不是成本。液冷系统的初始投资、维护成本、以及 PUE 数字背后一次侧水温是否用了"免费冷却"，都会改变最终账单。对比 TCO（总拥有成本）才有意义。

### 📊 底线数字速查

| 冷却方式 | 适用密度 | 典型 PUE 范围 | 冷却液 | 适用场景 |
|---------|---------|--------------|--------|---------|
| 风冷 | < 40 kW/rack 一档 | 1.3-1.6 | — | 8 卡 H100/B300 服务器 |
| DLC（冷板） | 30-100+ kW/rack | 可低至 1.1 附近 | **水-乙二醇**（导电） | NVL72 级 AI 集群 |
| 单相浸没 | 更高密度 | 可更低 | 介电液 | 定制服务器、新建 |
| 两相浸没 | 最高一档 | 可更低 | 沸点介电液 | 实验性/特定新建 |

> 表中 PUE 是"可达到的典型区间"，不是承诺值；具体取决于气候、水温与 CDU 效率。

### 💡 一句话记住

> **"液冷会不会成为标配，答案是'分场景'：NVL72 这类 130+ kW 的机柜没有第二选项，DLC 已经是标配；8 卡 14-15 kW 的整机，风冷仍然合理，液冷只是预留。而'液冷省电'要拆开看——它有降低 PUE 的潜力，但省不省钱取决于气候、电价和 CDU 效率，不是一句口号。"**

## 对后续的铺垫

液冷解决了 GPU 的"热"问题。但还有一个更根本的瓶颈正在逼近：**内存墙（Memory Wall）**。

在 HBM 产能不足、价格高昂的背景下，CXL 内存池化和光互联被寄予厚望——不过要先澄清：**CXL 池化的是主机 DRAM，不是 GPU 的 HBM**。这个区别决定了它到底能干什么。
