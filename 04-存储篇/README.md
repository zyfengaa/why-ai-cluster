# 第四篇：存储篇 — 数据的"血液循环系统"

## 本篇导读

GPU 算力是心脏，网络是神经系统，那**存储就是血液循环系统**。

没有存储，模型参数和数据没地方读；存储太慢，GPU 就得"等饭吃"——等着数据从硬盘读进来。在大型训练集群中，存储 I/O 会吃掉 **15-30% 的 GPU 利用率**。花几千万买的 GPU，可能有三分之一的时间在等你从硬盘读数据。

**因果链**：GPU 太快 → 存储跟不上 → NFS 性能不足 → 并行文件系统诞生 → Lustre/WEKA/GPFS 三选一 → GPU Direct Storage 加速 → Checkpoint 成为新的瓶颈 → 需要端到端数据流水线优化
