# 第 0 篇：导读与全景图

## 本篇导读

在进入具体技术之前，先建立全局视角。本篇帮你回答三个问题：

1. **怎么读这个教程？** — 阅读路线建议
2. **核心指标有哪些？** — 每个指标怎么理解、怎么查
3. **整个 AI 集群的发展逻辑是什么？** — 一条因果链串起所有章节
