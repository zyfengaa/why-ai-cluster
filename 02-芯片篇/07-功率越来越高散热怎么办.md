# Q: GPU 功率越来越高，散热怎么办？

## 为什么会有这个问题

看一组 GPU 功耗数据：

| 代际 | TDP | 对比 |
|------|-----|------|
| V100 (2017) | 300 W | 普通家用暖气片 |
| A100 (2020) | 400 W | 台式电暖器 |
| H100 (2022) | 700 W | 微波炉 |
| B200 (2025) | 1,000 W | 电磁炉 |
| **GB300 (2025-26)** | **1,400 W** | **一个小型空调** |

一个 DGX GB300 机箱（8 张 GPU）就是 **11,200 W**，相当于一组 10 台家用空调同时满功率运行。

**问题**：这些热量不排掉，GPU 会在几秒内过热降频，算力暴跌。

## 传统风冷为什么撑不住了

```
风冷原理：
┌──────────────────────────────────────┐
│  ╔══╗    ← 冷风吸入，穿过散热鳍片    │
│  ║GPU║   → 热风从机箱后部排出        │
│  ╚══╝                              │
│   风扇                              │
└──────────────────────────────────────┘
```

风冷的上限约在 **每机箱 40-50 kW**。超过这个值，再多的风扇也排不干净热量，因为：
1. 风的比热容太低——同样体积的介质，水能带走的能量是风的 **4,000 倍**
2. 风速加大→噪音飙升→风扇寿命缩短
3. 高密度部署下，前一排机箱排出的热风会被后一排吸入，形成"热岛"效应

GB300 机箱 11 KW，意味着高密度机架一般放 6 个 DGX → **66 kW 每机架**。风冷已经无法处理。

## 解决什么问题：液体冷却

### 方案一：直接液体冷却（DLC，Direct Liquid Cooling）

```
DLC 原理：
┌──────────────────────────────────┐
│       冷板（Cold Plate）           │
│   ┌─────────────────────────┐     │
│   │   微通道水流道           │     │
│   └─────────────────────────┘     │
│        │ 导热界面材料（TIM）        │
│   ┌─────────────────────────┐     │
│   │       GPU 芯片           │     │
│   └─────────────────────────┘     │
└──────────────────────────────────┘
```

- 冷却液通过冷板直接接触 GPU 上盖
- 带走 60-80% 的热量，剩下的靠辅助风冷
- 单相 DLC（水不沸腾）是 2026 年的 **实际标准**
- 支持 **100-240 kW/机架**

### 方案二：浸没式冷却

```
浸没式原理：
┌──────────────────────────────┐
│    ▲ ▲ ▲                     │
│   ┌─────────────────┐        │
│   │     服务器       │        │
│   │ ┌────┐ ┌────┐   │        │
│   │ │GPU │ │GPU │   │        │
│   │ └────┘ └────┘   │        │
│   └─────────────────┘        │
│   ═════════════════════════  │
│   介电冷却液                  │
└──────────────────────────────┘
```

- 整台服务器泡在介电液体中，液体不导电
- 100% 热量被液体带走，不需要风扇
- 支持 200+ kW/机架
- 2026 年 CAGR 26-34%，增速最快，但基数小

## 🛠 实操指南

### 📋 决策指南：你的集群需要什么散热方案？

**看 GPU 功耗密度决定：**

```
GPU 功耗 → 机箱功耗 → 机架功耗 → 确定散热方案

实测阈值：
  < 30 kW/机架 → 风冷足够（A100 时代）
  30-60 kW/机架 → 风冷 + 优化气流（部分 H100 集群）
  60-100 kW/机架 → 必须 DLC 液冷（H100 高密度 / B200）
  > 100 kW/机架 → DLC（GB300 NVL72 ~132 kW/机架）
  > 200 kW/机架 → 两相浸没式或 DLC + 辅助冷却
```

**2026 年具体建议：**

| GPU 配置 | 机架功耗 | 推荐散热 | 理由 |
|---------|---------|---------|------|
| 4× H100 SXM | ~3-4 kW | ✅ 风冷 | 功耗低，标准数据中心即可 |
| 8× H100 SXM（DGX） | ~10.2 kW | ⚠️ 风冷（需高气流） | 可风冷但需热通道隔离 |
| 8× B200（DGX） | ~14.3 kW | ⚠️ **建议 DLC** | 风冷边界，噪音大 |
| 8× GB300（DGX） | ~18 kW | ❌ **必须 DLC** | 1400W 每 GPU，风冷无效 |
| NVL72（72× B200） | ~132 kW | ❌ **必须 DLC** | 一机柜顶一个传统机房 |
| NVL576（576× Rubin） | 预计 >500 kW | ❌ **浸没或高密 DLC** | 下一代密度 |

**一条经验**：**2026 年微软已要求所有新 Azure AI 基础设施强制使用 DLC**（2026 年 2 月起）。如果你在采购新 GPU（B200/GB300），默认方案就是液冷，不需要考虑风冷。

### 🔧 自己动手验：你的 GPU 在过热降频吗？

```bash
# 1. 检查 GPU 温度
nvidia-smi --query-gpu=index,name,temperature.gpu,power.draw,clocks_throttle_reasons.active \
  --format=csv
# 温度正常范围：30-85°C
# > 85°C：开始降频
# > 95°C：严重过热，算力显著下降

# 2. 检查 GPU 是否因为温度在降频
nvidia-smi -q -d CLOCK | grep -E "Throttle|Slowdown|Reason"
# 如果 "Throttle Reasons" 显示 "HW Slowdown" 或 "Thermal" → 降频中！
# 正常状态：所有降频原因都是 "Not Active"

# 3. 检查实际的 Perf State（性能状态）
nvidia-smi -q -d PERFORMANCE | grep "Perf State"
# P0 = 最佳性能（满速）
# P1 = 轻度降频
# P2 = 显著降频（这说明散热有问题！）
# P12 = 最低性能（几乎不可用）

# 4. 长时间负载后检查功耗是否达标
# 运行训练任务 30 分钟后：
nvidia-smi --query-gpu=power.draw,power.limit --format=csv
# H100 应接近 700W（功率限制）
# 如果 power.draw 远低于 power.limit → GPU 因为过热降频了
# B200 应接近 1000W
# GB300 应接近 1400W

# 5. 液冷系统检查（如果已部署）
# 检查 CDU（冷却液分配单元）状态
# 进液温度：18-32°C，出液温度：35-50°C（单相 DLC）
# 温差 ΔT > 10°C 说明带走了足够的热量
```

### ⚠️ 常见误区

- **误区**："风冷也能压 1000W，加几个暴力风扇就行"
  - **实际**：风冷的上限约 50 kW/机架，超过这个值再大的风扇也排不掉。空气的比热容只有水的 **1/4000**——要想用风排掉 1000W 的热量，需要每秒吹过超过 30 立方米的空气，这已经是"飓风级"的风力了，对服务器的震动和噪音都是毁灭性的。

- **误区**："液冷太贵了，用风冷省成本"
  - **实际**：**风冷的 GPU 降频损失的成本远大于液冷**。一个 DGX GB300 机箱 11.2 kW，如果用风冷，GPU 会因为过热降频到 P2 状态（算力损失 30-50%）。液冷方案每机架增加的成本（3-5 万美元）相比省下的 GPU 算力，**几个月就回本**。2026 年之后的新采购，风冷不是省钱，是浪费。

- **误区**："液冷系统容易漏水，不安全"
  - **实际**：2026 年的 DLC 系统已经非常成熟。关键安全设计：① 负压系统（漏也是进气不是出水）；② 导电率传感器（一旦检测到漏液立即停机）；③ 快速断开接头（UQD）支持热插拔，断开时自动密封。Accelsius 2026 年 2 月的实测演示：**单 GPU 4,500W DLC 冷却**（40°C 温水进水），持续稳定运行无泄漏。

## 对后续的铺垫

液冷解决了散热，但带来了新的挑战：
1. **基础设施改造**：传统数据中心没有液冷管道，改造费用高昂
2. **运维复杂度**：漏水检测、CDU 冗余、负压系统
3. **高密度设计**：需要从"多少平米放一个机架"改为"多少 kW 放一个机架"

这也引出更大层面的问题：**万卡集群的能源和基础设施怎么规划？**
