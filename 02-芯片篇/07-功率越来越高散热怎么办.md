# Q: GPU 功率越来越高，散热怎么办？

## 为什么会有这个问题

看一组 GPU 功耗数据（单卡 TDP）：

| 代际 | 单卡 TDP | 对比 |
|------|-----|------|
| V100 (2017) | 300 W | 普通家用暖气片 |
| A100 (2020) | 400 W | 台式电暖器 |
| H100 (2022) | 700 W | 微波炉 |
| B200 (2025) | ~1,000 W | 电磁炉 |
| **GB300/B300 (2025-26)** | **1,400 W** | **一个小型空调** |

**但讨论散热时，看单卡 TDP 是不够的，要分三个层级：**

| 层级 | 定义 | 例子 |
|------|------|------|
| **GPU TDP** | 单颗 GPU 的热设计功耗 | GB300/B300 单卡 1,400 W，8 卡合计 **11.2 kW** |
| **整机** | 8 卡服务器（含 CPU、内存、网卡、风扇） | DGX B300 整机约 **14-15 kW** |
| **整柜** | 一个机柜（含交换机、供电、全部服务器） | **GB200/GB300 NVL72 整柜约 132 kW** |

> 注意：**"11.2 kW"是 8 颗 GPU 的 TDP 合计，不是整机功耗**。整机还要加上 CPU/内存/网络；而"必须液冷"的判断依据是**机柜功率密度**，不是单卡 TDP。

**问题**：这些热量不排掉，GPU 会在几秒内过热降频，算力暴跌。

## 传统风冷为什么撑不住了

```
风冷原理：
┌──────────────────────────────────────┐
│  ╔══╗    ← 冷风吸入，穿过散热鳍片    │
│  ║GPU║   → 热风从机箱后部排出        │
│  ╚════                              │
│   风扇                              │
└──────────────────────────────────────┘
```

风冷的上限约在**每机柜 20-50 kW**（取决于厂商和风道设计；注意是 per rack，不是 per chassis）。超过这个值，再多的风扇也排不干净热量，因为：
1. 空气的体积比热容太低——水约 4.2 MJ/(m³·K)，空气约 1.2 kJ/(m³·K)，**同体积下带热能力差约 3,500 倍**
2. 风速加大→噪音飙升→风扇寿命缩短
3. 高密度部署下，前一排机柜排出的热风会被后一排吸入，形成"热岛"效应

### 算一笔风量的账：1,000 W 真的要"30 m³/s"吗？

常见说法"1,000 W 需要 30 m³/s 空气"是量级错误。按热力学基本公式重算：

```
P = ṁ × c_p × ΔT

假设（典型数据中心条件）：
  空气比定压热容 c_p ≈ 1,005 J/(kg·K)
  空气密度 ρ ≈ 1.2 kg/m³
  温升 ΔT = 10 °C（出风 35°C − 进风 25°C）

体积流量 q = P / (ρ × c_p × ΔT)
  = 1,000 / (1.2 × 1,005 × 10)
  ≈ 0.083 m³/s（约 3 m³/min）
```

ΔT 取 5 °C 时约 0.17 m³/s，ΔT 取 15 °C 时约 0.06 m³/s。**所以 1,000 W 需要 0.08-0.17 m³/s 量级的空气流**——这是机房空调轻松可及的数字，绝不是"飓风级"。风冷真正的极限不在单卡 1,000 W，而在**整柜几十上百 kW 时的风道容量和热隔离难度**。

## 解决什么问题：液体冷却

### 方案一：直接液体冷却（DLC，Direct Liquid Cooling）

```
DLC 原理：
┌──────────────────────────────────┐
│       冷板（Cold Plate）           │
│   ┌─────────────────────────┐     │
│   │   微通道水流道           │     │
│   └─────────────────────────┘     │
│        │ 导热界面材料（TIM）        │
│   ┌─────────────────────────┐     │
│   │       GPU 芯片           │     │
│   └─────────────────────────┘     │
└──────────────────────────────────┘
```

- 冷却液是**水-乙二醇混合液**（不是"导电水"；它走密闭管路，不接触电路），通过冷板直接接触 GPU 上盖
- 带走大部分热量，剩下的靠辅助风冷
- 单相 DLC（液体不沸腾）是当前的**实际标准**
- 支持机柜密度约 **100-240 kW/柜**（厂商口径）

### 方案二：浸没式冷却

```
浸没式原理：
┌──────────────────────────────┐
│    ▲ ▲ ▲                     │
│   ┌─────────────────┐        │
│   │     服务器       │        │
│   │ ┌────┐ ┌────┐   │        │
│   │ │GPU │ │GPU │   │        │
│   │ └────┘ └────┘   │        │
│   └─────────────────┘        │
│   ═════════════════════════  │
│   介电冷却液（不导电）          │
└──────────────────────────────┘
```

- 整台服务器泡在**介电液体**（不导电，通常是氟化液或矿物油类）中
- 100% 热量被液体带走，不需要风扇
- 支持更高机柜密度，但改造成本高，部署基数仍小

### 两种方案一句话区分

> **DLC 用水-乙二醇（在管路里），浸没式用介电液（把服务器泡进去）。**

## 🛠 实操指南

### 📋 决策指南：你的集群需要什么散热方案？

**看机柜功率密度决定，不是看单卡 TDP：**

```
机柜功率 → 确定散热方案

经验阈值（厂商口径，具体以机房条件为准）：
  < 20 kW/机柜   → 常规风冷足够
  20-50 kW/机柜  → 风冷上限区间，需要精密风道/封闭冷热通道
  > 50 kW/机柜   → 基本必须 DLC 液冷
  > 100 kW/机柜  → DLC（NVL72 约 132 kW/柜就是典型）
  > 200 kW/机柜  → 高密 DLC 或浸没式
```

**具体配置对照：**

| GPU 配置 | 功率量级 | 推荐散热 | 理由 |
|---------|---------|---------|------|
| 4× H100 SXM | ~3-4 kW（仅 GPU） | ✅ 风冷 | 功耗低，标准数据中心即可 |
| 8× H100 SXM（DGX） | 整机 ~10-12 kW | ✅ 风冷（需良好风道） | 常规 H100 集群标配 |
| 8× B200（DGX B200） | 整机约 14-15 kW | ✅ 风冷可行 | 厂商支持风冷配置 |
| 8× GB300/B300（DGX B300） | 整机约 14-15 kW | ✅ 风冷可行 | **GPU 合计 11.2 kW ≠ 整机，14-15 kW 在风冷范围内** |
| NVL72（72× B200/GB300） | **整柜约 132 kW** | ❌ **必须 DLC** | 远超风冷 20-50 kW/柜上限 |
| NVL576（Rubin Ultra） | 约 600 kW/柜（NVIDIA 口径） | ❌ 高密 DLC/浸没 | 下一代密度 |

**一条经验**：判断要不要液冷，问"我的**机柜**多少 kW"，不要问"我的**GPU**多少 W"。8 卡 DGX B300 约 14-15 kW，风冷完全可行；NVL72 约 132 kW/柜，才是必须 DLC 的场景。

### 🔧 自己动手验：你的 GPU 在过热降频吗？

```bash
# 1. 检查 GPU 温度
nvidia-smi --query-gpu=index,name,temperature.gpu,power.draw,clocks_throttle_reasons.active \
  --format=csv
# 温度正常范围：30-85°C
# > 85°C：开始降频
# > 95°C：严重过热，算力显著下降

# 2. 检查 GPU 是否因为温度在降频
nvidia-smi -q -d CLOCK | grep -E "Throttle|Slowdown|Reason"
# 如果 "Throttle Reasons" 显示 "HW Slowdown" 或 "Thermal" → 降频中！
# 正常状态：所有降频原因都是 "Not Active"

# 3. 检查实际的 Perf State（性能状态）
nvidia-smi -q -d PERFORMANCE | grep "Perf State"
# P0 = 最佳性能（满速）
# P1 = 轻度降频
# P2 = 显著降频（这说明散热有问题！）
# P12 = 最低性能（几乎不可用）

# 4. 长时间负载后检查功耗是否达标
# 运行训练任务 30 分钟后：
nvidia-smi --query-gpu=power.draw,power.limit --format=csv
# H100 应接近 700W，B200 应接近 1000W，GB300/B300 应接近 1400W
# 如果 power.draw 远低于 power.limit → GPU 因为过热降频了

# 5. 液冷系统检查（如果已部署）
# 检查 CDU（冷却液分配单元）状态
# 进液温度：18-32°C，出液温度：35-50°C（单相 DLC）
# 温差 ΔT > 10°C 说明带走了足够的热量
```

### ⚠️ 常见误区

- **误区**："1,400 W 的 GPU 必须液冷，风冷无效"
  - **实际**：液冷看的是**机柜功率密度**。8 卡 DGX B300 整机约 14-15 kW（GPU 合计 11.2 kW），在风冷 20-50 kW/柜的能力范围内，风冷可行。**必须 DLC 的是 NVL72 这种约 132 kW/柜的整柜**。判断依据：先算"每机柜多少 kW"，再看机房的供风/回风能力。

- **误区**："1,000 W 的芯片要用风排掉，需要每秒 30 立方米空气"
  - **实际**：按 P = ρ·q·c_p·ΔT 计算（ρ≈1.2 kg/m³，c_p≈1,005 J/(kg·K)，ΔT 取 5-15 °C），1,000 W 只需要约 **0.06-0.17 m³/s** 的空气流。风冷的真正瓶颈是整柜几十 kW 时的风道总容量与热隔离，不是单卡算出来的风量。

- **误区**："液冷系统容易漏水，不安全"
  - **实际**：现代 DLC 系统有多重安全设计：① 负压系统（漏也是进气不是出水，取决于具体厂商设计）；② 泄漏检测（导电率/湿度传感器，检测到异常立即告警停机）；③ 快速断开接头（UQD）支持热插拔，断开时自动密封。而且冷却液是**水-乙二醇**，走密闭管路不接触电路；浸没式则用**介电液**，本身不导电。

### 📊 底线数字速查

| 指标 | 风冷 | DLC 单相 | 两相 DLC | 浸没式 |
|------|------|---------|---------|--------|
| 最大冷却密度 | **20-50 kW/机柜**（厂商相关） | **100-240 kW/机柜**（厂商口径） | 更高 | 更高 |
| pPUE（能源效率） | 1.15-1.30 | 1.02-1.20 | ~1.02 | ~1.01 |
| 冷却介质 | 空气 | **水-乙二醇**（密闭管路） | 水乙二醇/相变工质 | **介电液**（不导电） |
| 典型场景 | DGX 8 卡整机（10-15 kW） | NVL72（约 132 kW/柜） | 未来更高密 | 特殊密度/改造场景 |
| 改造难度 | — | 中等（需要管路+CDU） | 高 | 高（需要改造机房） |
| 噪音 | 高（风扇） | **低** | **极低** | **极低（无风扇）** |

## 对后续的铺垫

液冷解决了散热，但带来了新的挑战：
1. **基础设施改造**：传统数据中心没有液冷管路，改造费用高昂
2. **运维复杂度**：漏水检测、CDU 冗余、负压系统
3. **高密度设计**：需要从"多少平米放一个机柜"改为"多少 kW 放一个机柜"

这也引出更大层面的问题：**万卡集群的能源和基础设施怎么规划？**
