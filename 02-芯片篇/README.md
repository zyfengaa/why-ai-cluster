# 第二篇：芯片篇 — GPU 的进化与选择

## 本篇导读

"AI 训练为什么用 GPU 不用 CPU？"——这可能是最基础的问题，但它引出的答案贯穿了整个 AI 硬件架构。

本篇从 GPU 为什么会成为 AI 训练的核心开始，逐步深入到 **NVLink、NVSwitch、HBM、芯片选型** 等核心技术问题。你会发现，每一次芯片架构的升级，都是在解决一个具体的物理瓶颈。

**因果链**：GPU 比 CPU 适合并行 → 但 PCIe 卡住了 GPU 通信 → NVLink 绕过 PCIe → 8 卡以上又卡住了 → NVSwitch 解放全互联 → 显存不够了 → HBM 堆叠解决 → 芯片越来越热 → 液冷成为必需品
