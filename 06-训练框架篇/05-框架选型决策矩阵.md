# Q: 在实际场景中怎么选？— 2026 年框架选型决策矩阵

## 为什么会有这个问题

现在你了解了三个主要框架的各自定位：

| 框架 | 一句话 | 最强项 |
|------|--------|--------|
| **FSDP2** | PyTorch 原生，最简单 | 微调 + 中小模型 |
| **DeepSpeed** | 微软出品，功能最全 | 内存受限 + 长上下文 + MoE |
| **Megatron-Core** | NVIDIA 工业级，性能最高 | 超大模型预训练 |

但实际项目不会只用"最好的框架"——你需要根据场景做选择。

## 2026 年选型决策树

```
第一步：你的模型规模有多大？
│
├─ < 7B（单卡能装下）
│   └→ DDP 或 FSDP2 NO_SHARD（最简单，不需要 ZeRO）
│
├─ 7B - 34B（单机 8 卡基本能装）
│   └→ FSDP2 FULL_SHARD（首选，API 最简洁）
│      └→ 需要长上下文（> 32K）？→ DeepSpeed-Ulysses
│
├─ 34B - 70B（多节点必须）
│   └→ FSDP2 FULL_SHARD + TP=8（PyTorch 2.5+ 原生支持）
│      └→ 显存极度紧张？→ DeepSpeed ZeRO-3 + CPU Offload
│
└─ > 70B（百亿级预训练）
    └→ Megatron-Core（TP+PP+DP+SP 4D 并行）
       └→ MoE 模型？→ Megatron-Core MoE 或 DeepSpeed-MoE

第二步：你的场景是？
│
├─ 微调（Fine-tuning）
│   └→ FSDP2（简单、生态好、支持 LoRA）
│
├─ 全量微调（Full fine-tune）
│   └→ FSDP2 + TP（70B 以下）或 Megatron-Core（70B 以上）
│
├─ 预训练（Pre-training from scratch）
│   └→ 70B+ → Megatron-Core（稳定、MFU 最高）
│   └→ < 70B → FSDP2 或 DeepSpeed ZeRO-3
│
└─ 研究/实验
    └→ FSDP2（快速迭代，不锁死在特定框架）
```

---

## 各场景的详细推荐

### 场景 1：LoRA 微调 7B-13B 模型

| 维度 | 推荐 |
|------|------|
| 框架 | **FSDP2 + PEFT** |
| 配置 | SHARD_GRAD_OP 或 NO_SHARD |
| GPU | 1-8 卡 |
| 理由 | 最简单，HuggingFace PEFT 原生集成 |
| 代码量 | 3 行修改 |

### 场景 2：全量微调 34B-70B 模型

| 维度 | 推荐 |
|------|------|
| 框架 | **FSDP2 FULL_SHARD** |
| 配置 | FULL_SHARD + TP=8（如果单层大） |
| GPU | 8-64 卡 |
| 理由 | API 简洁，torch.compile 加速 |
| 预期 MFU | 40-55% |

### 场景 3：长上下文训练（> 32K tokens）

| 维度 | 推荐 |
|------|------|
| 框架 | **DeepSpeed-Ulysses** 或 **Megatron-Core SP** |
| 理由 | FSDP2 的长上下文支持不如 Ulysses 成熟 |
| 注意 | Ulysses 自动处理序列切分，与 ZeRO-3 兼容 |

### 场景 4：70B+ 模型预训练

| 维度 | 推荐 |
|------|------|
| 框架 | **Megatron-Core + NeMo** |
| 配置 | TP=8, PP=4-8, DP=4-16, SP=（可选） |
| GPU | 128-1024 卡 |
| 理由 | 工业级稳定，MFU 最高（45-55%） |
| 学习成本 | 高 |

### 场景 5：MoE 模型训练

| 维度 | 推荐 |
|------|------|
| 框架 | **Megatron-Core MoE** 或 **DeepSpeed-MoE** |
| 理由 | FSDP2 不支持 EP，只有这两个框架支持 |
| 选择 | Megatron + EP 性能更优，DeepSpeed 配置更灵活 |

### 场景 6：研究/快速实验

| 维度 | 推荐 |
|------|------|
| 框架 | **FSDP2 + torch.compile** |
| 理由 | 不锁死在特定框架，代码可移植 |
| 工具 | HuggingFace Accelerate + FSDP2 |

## 框架兼容性速查

| 需求 | FSDP2 | DeepSpeed | Megatron-Core |
|------|-------|-----------|---------------|
| PyTorch 原生 | ✅ 原生 | ⚠️ 外部依赖 | ❌ 完全独立 |
| HuggingFace | ✅ 原生 | ✅ 深度集成 | ❌ 需要转换 |
| torch.compile | ✅ 兼容 | ⚠️ 不兼容 | ⚠️ 部分兼容 |
| FP8 训练 | ⚠️ torch.compile | ❌ | ✅ Transformer Engine |
| LoRA 支持 | ✅ PEFT 集成 | ✅ DeepSpeed-LoRA | ❌ |
| CPU Offload | ⚠️ 基本 | ✅ ZeRO-Infinity | ❌ |
| NVMe Offload | ❌ | ✅ 唯一方案 | ❌ |
| MoE | ❌ | ✅ DeepSpeed-MoE | ✅ Megatron-EP |
| 长上下文 | ⚠️ 有限 | ✅ Ulysses | ✅ Megatron-SP |
| 弹性训练 | ✅ DCP | ❌ | ⚠️ 有限 |
