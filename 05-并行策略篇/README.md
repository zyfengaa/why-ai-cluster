# 并行策略篇 — 如何让千卡协同工作

## 本篇章回答的问题

| Q&A | 核心链条 |
|------|---------|
| Q1: 数据并行（DP）是怎么工作的？ | 最早的并行方式，All-Reduce 同步梯度 |
| Q2: 显存放不下整个模型怎么办？ | 张量并行（TP）— 层内切分 |
| Q3: 层数太多怎么办？ | 流水线并行（PP）— 层间切分 |
| Q4: 这几种并行能组合吗？ | 3D 并行（TP+PP+DP）的工程权衡 |
| Q5: 长序列训练为什么需要序列并行（SP）？ | Attention 的内存爆炸 |
| Q6: MoE 模型为什么需要专家并行（EP）？ | 稀疏激活的计算模式 |
| Q7: 这些并行策略哪个最好？ | 2026 年的选型决策树 |

**核心因果链**：单卡放不下模型（TP）→ 层太多（PP）→ 数据量太大（DP）→ 序列太长（SP）→ 模型太大且稀疏（MoE+EP）
