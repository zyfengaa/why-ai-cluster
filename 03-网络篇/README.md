# 第三篇：网络篇 — 集群的"神经系统"

## 本篇导读

GPU 算力再强，如果数据送不过去、结果传不出来，一切都是空谈。

NVLink 解决了**机箱内** GPU 之间的通信（[[02-芯片篇/02-PCIe瓶颈与NVLink诞生]]），但一旦扩展到几百、几千张 GPU，就需要通过网络把多台服务器连起来。网络就是 AI 集群的神经系统——它决定了所有 GPU 能否像一个整体一样协同工作。

**因果链**：多机需要互联 → 需要 RDMA 技术 → 两种路线：InfiniBand 和 RoCEv2 → IB 可靠但贵，RoCE 便宜但运维难 → UEC 试图结合两者优势 → 拓扑结构影响扩展效率
