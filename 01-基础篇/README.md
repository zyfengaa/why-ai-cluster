# 第一篇：基础篇 — 为什么需要 AI 集群？

## 本篇导读

从这个问题开始：**你训练一个模型，单张 GPU 跑不动了，怎么办？**

答案似乎很直观——加更多的 GPU。但"加卡"这两个字背后，涉及一连串不直观的技术问题。本篇从最朴素的需求出发，一步步推导出集群存在的必要性。

**因果链**：模型变大 → 单卡跑不动 → 多卡并行 → 需要通信 → 通信成为瓶颈 → 需要专门设计集群
